# ── Engines VI–IX: Blender (system install) ──────────────────────────────────

# Blender 4.3 or later — REQUIRED for Engines VI, VII, VIII, IX
#   Download: https://www.blender.org/download/
#   Must be accessible as `blender` on PATH, or pass full path to engine config.
#
#   Why Blender and not bpy pip package?
#     The standalone `bpy` PyPI package is experimental and lacks Bullet physics,
#     Mantaflow fluids, Eevee-Next renderer, and the AOV compositor nodes.
#     Headless CLI mode (`blender --background --python script.py`) is the
#     recommended approach and is what all engines use internally.
#
#   Blender capabilities used:
#     • Bullet rigid body physics + ptcache.bake_all  (VI–IX)
#     • Mantaflow fluid simulation                    (VI–VII)
#     • Eevee-Next renderer + Workbench wireframe     (VI–IX)
#     • Compositor: Depth AOV, Normal AOV, Beauty     (VI–IX)
#     • bpy.ops.wm.usd_import — USD asset pipeline   (VIII–IX)
#     • WORKBENCH/WIREFRAME render for PixelAuditor   (IX)
#
# bpy (optional, experimental):
#   pip install bpy  — limited to geometry scripting, no physics/renderer
